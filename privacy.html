Privacy Policy

Personal Health Dashboard · Last updated 2 October 2026

1. Who this covers

"Personal Health Dashboard" (the "Application") is a private, locally-run tool operated by its owner for the sole purpose of viewing the owner's own Google Health data. The Application has exactly one user and is not made available to the public. There are therefore no other data subjects, and no data belonging to anyone else is collected, processed or stored.

2. What Google user data is accessed

Access is granted by the owner through Google's OAuth 2.0 consent flow. The Application requests read-only scopes only from the Google Health API:

ScopeData
googlehealth.activity_and_fitness.readonlyActivity, workouts, steps
googlehealth.health_metrics_and_measurements.readonlyWeight, body-fat percentage, heart rate, HRV, SpO2, respiratory rate
googlehealth.sleep.readonlySleep sessions and stages
googlehealth.nutrition.readonlyNutrition and hydration entries
googlehealth.logged_symptoms.readonlyLogged symptoms
googlehealth.mindfulness.readonlyMindfulness sessions
googlehealth.ecg.readonlyECG recordings
googlehealth.irn.readonlyIrregular rhythm notifications
googlehealth.settings.readonlyGoogle Health settings
googlehealth.profile.readonlyProfile information

No write, edit or delete scopes are requested. The Application cannot create, modify or remove any data in the owner's Google Account.

3. How the data is used

Solely to display the owner's own health data back to the owner: as a dashboard of current metrics and trends, and as a local daily spreadsheet. The data is used for the owner's personal tracking and for no other purpose.

4. How the data is stored

  • OAuth credentials. The refresh token is stored on the owner's own computer, encrypted with the Windows Data Protection API (DPAPI), which binds decryption to the owner's Windows user account. It is never transmitted to any third party.
  • Health data. Retrieved data is written to files on the owner's own computer and is not uploaded to any server operated by the Application.
  • The Application operates no servers, no databases and no cloud storage of its own.

5. How the data is shared

It is not shared. Google user data obtained by this Application is never sold, rented, traded, transferred or disclosed to any third party; is not used for advertising, marketing or profiling; is not used to train machine-learning models; and is not used for any purpose other than those described in section 3.

6. Limited Use disclosure

The Application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Retention and deletion

The owner may revoke the Application's access at any time at myaccount.google.com/permissions. Locally stored health data and the encrypted token can be deleted at any time by deleting the relevant files from the owner's computer. Because the Application stores nothing on any server, revoking access and deleting the local files removes all data held by the Application.

8. Changes

Any change to this policy will be published on this page with an updated date. Because this is a single-user tool, changes affect only that user.
