Personal Health Dashboard

A private, single-user tool for viewing the owner's own Google Health data.

What this application does

This application reads health and fitness data from a single Google Account — the account of its owner — through the Google Health API, and presents it as a personal dashboard and a local spreadsheet of daily trends. It is used to track long-term personal metrics such as weight, body-fat percentage, resting heart rate, heart-rate variability, sleep and steps.

How it is used

The application runs only on the owner's own computer. It is not offered to the public, it has no other users, it accepts no sign-ups, and it does not collect data from anyone else.

Google user data

Access is granted by the owner through Google's standard OAuth 2.0 consent flow, using read-only Google Health scopes. The application can read the owner's health data; it cannot modify or delete it. OAuth refresh tokens are stored encrypted on the owner's own device using the Windows Data Protection API (DPAPI) and are never transmitted to any third party. No Google user data is shared, sold, or used for advertising.

Privacy policy

Full details of what is accessed, how it is stored, and how it is deleted are in the privacy policy.
